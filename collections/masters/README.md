# 거장의 문장

앱은 [문장 파일 목록](manifest.json)을 읽어 ‘거장의 문장’ 1,111개를 보여 줍니다. ‘마음의 문장’ 1,111개는 저장소 루트의 `quotes.json`에 있습니다.

## 수록 내용

- 기존 거장 문장 521개에 원문과 출처를 확인한 590개를 더했습니다. 새로 실은 자료에는 기존 수집본에서 다시 대조한 문장과 전자책 본문에서 발췌한 문장이 함께 들어 있습니다. 번역본을 사용한 경우 영문 번역자와 작품 링크를 달았습니다. 소설과 대화편의 문장에는 작품 저자를 표시합니다.
- 각 카드에 사유 질문과 행동 질문을 붙였습니다. 기존 수집본에서 온 사유 질문을 보존했고, 나머지에는 원문 표현과 주제를 바탕으로 질문을 붙였습니다. 행동 질문은 주제별로 오늘 해 볼 작은 실습을 제시합니다.
- 새 영어 문장의 한국어 번역 중 자동 초안에는 카드에 ‘번역 초안’ 표시가 나옵니다. 초안은 NLLB-200의 [공개 모델](https://huggingface.co/facebook/nllb-200-distilled-600M)을 참고해 작성했습니다. 한글 읽기는 영어 발음 사전과 근사 표기를 이용했습니다.
- ‘랜덤 이야기’에서 배움, 창작, 일과 관계 중 주제를 골라 10장 또는 30장으로 읽을 수 있습니다. 새 문장도 주제에 맞으면 뽑힙니다.

## 문장 추가

1. 기존 카드 형식을 복사합니다. 수집본의 A, H, Q 번호를 유지하고, 새 문장에는 다른 카드와 겹치지 않는 번호를 씁니다.
2. 영문, 한국어 뜻, 한글 읽기, 저자, 출처 링크, 주제, 사유 질문과 행동 질문을 적습니다. 영문을 원자료와 대조한 뒤 `source_text_checked`를 `true`로 적습니다. 한국어 번역이 초안이면 `translation_draft`를 `true`로 적습니다.
3. 기존 파일에 추가하거나 새 파일을 만들어 `manifest.json`에 파일명을 넣습니다.
4. 저장소 루트에서 `python3 scripts/audit_collections.py`를 실행합니다. 두 모음 사이의 정확 일치, 포함 인용, 유사 문구와 필수 항목을 점검합니다.
