# 거장의 문장

이 폴더에는 앱의 ‘거장의 문장’에 싣는 [공개용 문장](quotes.json)을 둡니다. ‘마음의 문장’ 데이터는 루트의 `quotes.json`에 있습니다.

## 문장 추가

1. `quotes.json`의 카드 형식을 복사합니다. 수집본에 이미 붙인 Q 번호를 그대로 쓰고, 기존 카드의 번호를 바꾸지 않습니다.
2. 영문과 한국어 뜻, 한글 읽기, 저자, 출처 위치와 링크, 주제를 적습니다. 영문을 원자료에서 대조하고 공개할 수 있는 본문인지 확인한 뒤 `source_text_checked`를 `true`로 적습니다.
3. 밑줄로 뜻을 보여 줄 표현이 있으면 `learning.words`에 영문 표현과 뜻을 넣습니다. 출처 아래에 맥락과 생각할 질문을 추가할 수 있습니다.
4. 저장소 루트에서 `python3 scripts/audit_collections.py`를 실행합니다. 기존 두 모음과 원문이 같거나, 한쪽에 포함되거나, 단어 배열이 매우 비슷한 문장을 찾습니다. 번호나 필수 항목에도 문제가 있으면 종료 코드 1을 반환합니다. 비슷한 뜻을 다른 표현으로 쓴 문장은 편집자가 확인합니다.
5. 서버에서 ‘거장의 문장’을 열어 카드 수와 읽기 화면을 확인합니다. 앱은 이 폴더의 JSON을 읽으므로 새 문장마다 HTML을 수정할 필요가 없습니다.

2026-11-24 기준, 첫 공개본은 오래된 원자료에서 확인한 4개입니다. 전체 수집본 1,517개를 마음의 문장 1,111개와 대조해 원문 일치 17쌍, 포함 인용 9쌍, 유사 후보 3쌍을 찾았습니다. 첫 공개본에 해당하는 후보는 0쌍입니다.
