# 거장의 문장

앱은 [문장 파일 목록](manifest.json)을 읽어 ‘거장의 문장’ 521개를 보여 줍니다. ‘마음의 문장’ 1,111개는 저장소 루트의 `quotes.json`에 있습니다.

초기 4개에 첨부 수집본에서 찾은 517개를 더했습니다. 첨부 인용문 중 541개를 해당 제목의 Standard Ebooks 본문 40종과 대조하고, 원문이 겹치거나 한 문장이 다른 문장에 포함되거나 표기만 비슷한 24개를 제외했습니다. 원문 대조는 대소문자, 띄어쓰기, 문장부호 차이를 허용합니다. 새 카드에는 실제 대조한 전자책 장의 링크와 영문 번역자, 한국어 뜻과 읽기 참고 표기를 담았습니다. 한글 읽기는 발음 사전과 수동 보완을 활용한 근사치입니다.

‘랜덤 이야기’에서 배움, 창작, 일과 관계 중 주제를 골라 10장 또는 30장으로 읽을 수 있습니다. 각 이야기는 세 단계로 나뉘며, 같은 문장을 한 이야기 안에 두 번 넣지 않습니다. 새로 추가한 문장도 이야기 주제와 태그가 맞으면 후보에 들어갑니다.

## 문장 추가

1. 기존 카드 형식을 복사합니다. 수집본의 A, H, Q 번호는 유지합니다. 새 문장에는 다른 카드와 겹치지 않는 번호를 씁니다.
2. 영문과 한국어 뜻, 한글 읽기, 저자, 출처 위치와 링크, 주제를 적습니다. 영문을 원자료에서 대조하고 공개할 수 있는 본문인지 확인한 뒤 `source_text_checked`를 `true`로 적습니다.
3. 기존 문장 파일에 추가하거나 `batch-007.json`처럼 새 파일을 만들고 `manifest.json`에 파일명을 추가합니다.
4. 저장소 루트에서 `python3 scripts/audit_collections.py`를 실행합니다. 기존 두 모음의 원문 일치, 포함 인용, 유사 문구, 번호와 필수 항목을 확인합니다. 비슷한 뜻을 다른 표현으로 쓴 문장은 편집자가 확인합니다.
5. 서버에서 ‘거장의 문장’을 열어 카드 수와 읽기 화면을 확인합니다.
