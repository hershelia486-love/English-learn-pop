# 제작·인수인계서

이 저장소의 대상은 **마음에 남는 영어 한 문장**이다. 현재의 화면과 데이터는 루트 `index.html`, `quotes.json`, `collections/masters/`가 기준이다. 이 문서는 구현 위치와 동작 계약을 설명한다. [공개 앱](https://english-learn-pop.vercel.app/) · [기술·기능 용어](terms.md)

## 1. 같은 앱 다시 실행하기

1. 저장소를 복제한다. 특정 배포를 재현할 때는 그 배포에 연결된 커밋을 체크아웃한다.
2. 루트의 `index.html`, `quotes.json`, `collections/masters/manifest.json`과 그 목록의 모든 JSON을 경로 그대로 복사한다.
3. 루트에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/`에 접속한다. 화면 HTML 안에 CSS와 순수 JavaScript가 들어 있다. 앱을 띄우는 데 패키지 설치, 빌드, 외부 폰트, API 키, 서버 데이터베이스가 필요 없다.
4. 기존 소스를 대상으로 기능을 수정한다. 포팅하는 경우에도 기존 DOM 구조, 스타일, 공개 데이터, 아래 검수 기준을 함께 옮긴다. 브라우저나 운영체제가 달라지면 시스템 글꼴과 읽어 주는 음성은 달라질 수 있다.
5. 배포할 때 저장소 루트를 정적 사이트로 제공한다. 현재 운영판은 GitHub `main`과 연결한 Vercel 배포다. 배포된 첫 화면과 두 모음의 JSON 요청까지 확인한다.

## 2. 화면과 상태

| 화면 | 시작·이동 | 확인할 결과 |
|---|---|---|
| 문장 목록 | 처음 열면 ‘마음의 문장’. 모음 버튼으로 전환 | 모음별 1,111개. 처음 40개를 그리고 ‘문장 더 보기’마다 40개씩 추가 |
| 한 장씩 | 상단 ‘한 장씩’ → 전체 화면 읽기 창 | 목록과 같은 무작위 순서. 첫 카드부터 시작하며 하단 이전·다음, ←·→, ↑·↓, PageUp·PageDown, 위아래 밀기를 지원 |
| 즐겨찾기 | 카드의 ‘마음에 담기’와 상단 ‘즐겨찾기’ | 현재 모음에서 저장한 카드만 표시. 다시 누르면 해제. 새로고침 뒤에도 같은 브라우저에서 유지 |
| 랜덤 이야기 | 마음의 문장은 기분, 거장의 문장은 주제를 골라 10장 또는 30장 읽기 | 3단계 구성. 10장은 3·4·3장, 30장은 10·10·10장. 닫아도 페이지가 열린 동안 이어 읽기 가능 |

- **공통 순서** — `loadCollection()`이 각 모음 데이터를 처음 읽으면 `shuffledQuotes()`가 전체 배열의 복사본을 섞는다. 이 순서를 `readingOrder`로 기억한다. 목록과 한 장씩은 이 배열을 공유한다. 새로고침이나 새 페이지 로드에는 다시 섞인다. 모음 버튼을 오가도 같은 페이지에서는 이미 섞은 순서를 재사용한다. 즐겨찾기에는 원래 데이터 순서를 쓴다.
- **검색과 주제** — `filtered()`가 영어, 번역, 저자, 출처, 주제에서 검색어를 부분 일치로 찾는다. 영문 대소문자를 구분하지 않으며 주제 조건과 함께 적용한다. 검색어만 지우는 × 버튼과 검색·주제를 함께 지우는 빈 결과 버튼이 있다. 한 장씩에도 목록의 검색·주제 조건을 적용하며, 읽기 화면에서 주제를 바꾸면 첫 카드로 간다. 모음을 바꾸면 검색과 주제 조건을 초기화한다.
- **읽기 조작** — `moveReel(step)`이 시작과 끝을 넘지 않도록 현재 위치를 제한한다. 한 장씩의 양 끝에서 해당 버튼을 끄고, 긴 카드에 스크롤할 내용이 남으면 해당 방향의 터치는 먼저 본문을 스크롤한다. 닫기나 Esc로 읽기 창을 닫는다. 모달의 배경 조작은 막고, 닫을 때 메뉴나 이어 읽기 버튼에 초점을 돌려준다.
- **랜덤 이야기** — `buildStoryDeck()`이 주제에 맞는 후보를 고르고 같은 문장 ID를 덱 안에서 두 번 쓰지 않는다. 마음의 문장은 단계별 후보 ID, 거장의 문장은 단계별 주제 태그를 쓴다. 직전에 본 문장은 같은 조건의 새 후보가 있으면 피한다. 이 순서는 일반 읽기의 `readingOrder`와 별개다.
- **저장** — `toggleFavorite()`가 기존 `localStorage` 키 `seon_quote_favorites_v1`에 ID 배열을 JSON으로 기록한다. 마음의 문장 ID는 숫자, 거장의 문장 ID는 문자열이다. 저장 성공에만 표시와 저장 상태를 바꾸고 실패 안내를 보여 준다. 기기·브라우저·사이트 주소별로 저장 영역이 다르다.

## 3. 카드 한 장의 구성

1. 주제와 고유 번호, 영어 원문.
2. 한글 읽기 펼치기, 한국어 번역, 해당하는 경우 ‘번역 초안’ 표시.
3. 모든 카드의 ‘맥락·적용 질문’ 펼치기. `quoteReadingGuide()`가 문장별 기록과 표현·주제에 맞춘 풀이를 사용한다. 출전 맥락이 없는 해석에는 ‘문장 풀이’를 붙인다.
4. ‘한 장씩’에서 데이터에 `learning.association`이 있는 경우에만 ‘장면 떠올리기’ 문구를 표시한다. 현재 마음의 문장 11개에 있다.
5. 저자와 출처 펼치기, 영어 듣기, 즐겨찾기.

밑줄 표현은 `buildFocusRanges()`, `renderEnglish()`, `meaningFor()`가 처리한다. 뜻은 문장별 보정 → 해당 문장의 `learning.words` → 공용 사전 순으로 찾는다. 뜻이 있는 표현을 버튼으로 그리고, 터치·클릭하면 같은 카드 안에서 한 번에 한 뜻을 펼친다. 다시 누르면 접힌다. ‘장면 떠올리기’ 아래에 단어 뜻 목록을 반복해서 붙이지 않는다. 영어 듣기는 브라우저 `speechSynthesis`에 영어 원문과 `en-US`, 속도 `0.82`를 넘긴다.

## 4. 데이터 파일과 수정 절차

| 파일 | 역할 |
|---|---|
| `data/quotes.master.json` | 마음의 문장 편집 기준 |
| `quotes.json` | 마음의 문장 공개 실행 데이터 |
| `collections/masters/manifest.json` | 거장의 문장 공개 파일 목록. 현재 `quotes.json`과 배치 13개 |
| `collections/masters/*.json` | 목록에 등록한 거장의 문장 데이터. 파일별 JSON 배열 |
| `data/pronunciation-overrides.json` | 발음 초안 작성 때 쓰는 예외 사전 |
| `data/review-changes.json`, `AUDIT.md` | 데이터 검수 기록 |

공통 필드는 `id`, `quote_en`, `quote_ko`, `pronunciation_ko`, `author`, `source`, `keyword`, `tags`다. 기존 항목의 ID와 타입을 유지한다. `source_url`은 원자료 링크, `source_text_checked`는 원자료 본문과 대조한 여부다. 거장의 문장 검수 스크립트는 `A-`, `H-`, `Q-` 뒤 네 자리 숫자와 `reflection_question`, `action_question` 필드도 검사한다. 화면의 질문 표시 방식은 `quoteReadingGuide()`가 정하며 파일의 두 질문 필드를 그대로 두 칸으로 출력하지 않는다. 선택 항목 `translation_draft`, `usage_note`, `learning.words`, `learning.association`은 해당 문장에만 붙인다.

마음의 문장 수정은 편집 원본에서 시작한다. 깨끗한 체크아웃의 루트에서 `python3 scripts/complete_quotes.py`를 실행해 공개 JSON을 갱신한다. 거장의 문장은 배치 파일을 편집하고, 새 배치라면 매니페스트에도 추가한다. 발음 초안 도구를 실행할 때만 `requirements.txt`의 `cmudict`가 필요하다.

## 5. 화면 재현 기준과 검수

[디자인 기준](../DESIGN.md)의 색·크기를 사용한다. 가로 850px부터 목록의 영문과 번역을 나란히 배치한다. 650px 이하는 좁은 화면용 메뉴와 검색 배치를 적용한다. 한 장씩은 영어 25px, 번역 15px, 한글 읽기 본문 12px, 펼치기 제목 9px, 단어 뜻 12px를 기준으로 한다. Lucian #048 선택 밑줄, #092 검색, #012 책갈피는 이미 소스에 들어 있다. 해당 코드를 옮길 때 저장소의 라이선스 고지도 함께 둔다.

```sh
python3 scripts/audit_quotes.py
python3 scripts/audit_collections.py
```

브라우저에서 아래 순서로 확인한다.

1. 375px와 1440px에서 두 모음을 열어 각 1,111개를 확인한다. 가로로 밀리지 않고 읽기 화면의 이전·다음 버튼이 보이는지 살핀다.
2. 각 모음에서 목록 첫 두 장의 ID와 한 장씩의 첫 두 ID를 대조한다. 이전·다음, 좌우 방향키, 모바일 밀기를 확인한다. 새로고침한 뒤 순서가 새로 섞이는지 첫 여러 장으로 비교한다.
3. ‘Love, and you shall be loved.’를 검색해 ‘한 장씩’으로 연다. 마음의 문장 #1에서 ‘Love’를 눌러 뜻을 열고 닫는다. ‘맥락·적용 질문’을 펼치고 ‘장면 떠올리기’ 문구를 확인한다. 거장의 문장 ‘I never saw my mother’로 검색한 뒤 #H-1027 번역에 밤에 만났다는 내용과 짧은 만남이 들어 있는지 확인한다.
4. 주제를 좁히고 검색어를 지운다. 없는 검색어의 빈 결과에서 조건을 초기화한다. 한 장만 남은 한 장씩 화면에서는 이전·다음이 모두 꺼지는지 확인한다.
5. 같은 브라우저에서 문장 저장 → 즐겨찾기 확인 → 새로고침 → 해제를 실행한다. 읽기 화면에서는 저장 뒤 같은 문장에 머무는지 확인한다.
6. 두 모음의 랜덤 이야기에서 10장과 30장을 열어 넘겨 보고, 닫았다 이어 읽는다. 실제 기기에서 영어 듣기와 위아래 밀기도 점검한다.
