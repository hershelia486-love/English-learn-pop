# 이 앱에서 쓴 기술과 기능 용어

버튼의 이름, 적용 범위, 동작 시점을 함께 말하면 수정할 부분을 찾기 쉽다. 아래 용어는 현재 앱의 코드와 화면에서 쓰는 것만 모았다. [제작·인수인계서](rebuild.md)

## 기능을 설명할 때

| 하고 싶은 수정 | 쓰면 좋은 용어 | 바로 쓸 수 있는 요청 |
|---|---|---|
| 새로 열 때 뒷부분의 문장도 위로 올라오게 하기 | 셔플, 페이지 로드, 순서 공유 | “두 모음의 전체 문장을 페이지가 열릴 때 한 번씩 섞어 줘. 목록과 한 장씩은 같은 순서를 쓰고, 검색이나 화면 전환으로 다시 섞이지 않게 해 줘.” |
| PC에서도 카드 넘기기 | 이전·다음 버튼, 키보드 탐색 | “한 장씩 화면 하단에 이전·다음 버튼을 고정해 줘. 좌우 방향키로도 넘기고, 첫 장과 마지막 장에서 해당 버튼을 꺼 줘.” |
| 모바일에서 본문 읽기와 넘기기 구분 | 세로 스와이프, 카드 내부 스크롤 | “긴 문장을 스크롤하는 중에는 다음 카드로 넘기지 말아 줘. 더 읽을 내용이 없는 방향으로 밀었을 때만 넘겨 줘.” |
| 눌러야 내용이 보이는 칸 | 접기·펼치기, 기본 접힘 | “‘맥락·적용 질문’ 제목은 모든 카드에 표시하고, 내용은 기본으로 접어 둬. 장면을 떠올리는 별도 문구에는 같은 이름표를 달아 줘.” |
| 영어 표현의 뜻이 두 곳에 나올 때 | 인라인 뜻 풀이, 문장별 뜻 보정 | “밑줄 친 단어를 눌렀을 때 카드 안에 뜨는 뜻만 써 줘. 한 장씩 하단의 반복 목록은 빼고, ‘장면 떠올리기’는 남겨 줘.” |
| 번역 문장이 중간에서 끊겨 보일 때 | 원본 데이터 누락, 화면 잘림 | “먼저 JSON의 `quote_ko`에 번역이 끝까지 있는지 확인해 줘. 원문 절이 빠졌으면 번역을 보완하고, 데이터가 온전하면 카드의 스크롤과 높이를 확인해 줘.” |
| 저장하고 다시 열어도 보이게 하기 | 로컬 저장, 저장 키, 상태 알림 | “기존 즐겨찾기 키와 문장 ID를 유지해 줘. 저장할 때만 완료 문구를 띄우고, 새로고침 후 즐겨찾기에서 확인해 줘.” |
| 작은 화면에서 글자만 고치기 | 반응형 배치, CSS 픽셀 | “‘한 장씩’에서 영어 25px, 번역 15px만 적용해 줘. 목록은 별도로 두고 375px 화면에서 긴 문장의 줄바꿈을 확인해 줘.” |

## 코드를 읽을 때

| 용어 | 쉬운 뜻 | 이 앱에서 쓰는 곳 |
|---|---|---|
| 정적 웹앱 | 서버가 미리 준비한 파일을 보내면 브라우저가 화면과 동작을 처리한다. | `index.html`과 JSON을 같은 주소에서 제공한다. |
| HTML · CSS · JavaScript | 화면의 뼈대, 모양, 누르면 일어나는 일을 맡는다. | 세 가지가 모두 `index.html`에 들어 있다. |
| DOM · 이벤트 | DOM은 브라우저에 올라간 화면 구조다. 이벤트는 클릭·입력·키보드 같은 조작 신호다. | `render()`가 카드와 모달 내용을 갱신한다. 버튼 이벤트를 처리해 저장하거나 넘긴다. |
| 반응형 · 미디어 쿼리 | 화면 너비나 입력 방식에 따라 배치를 바꾸는 CSS 규칙이다. | 넓은 목록의 좌우 배치와 모바일의 위아래 배치, 터치·키보드 안내에 쓴다. |
| 고정 메뉴 · 모달 | 고정 메뉴는 스크롤해도 화면 위에 남는다. 모달은 열려 있는 동안 뒤 화면을 조작하지 못하게 한다. | 상단 메뉴는 `position: sticky`, 한 장씩은 전체 화면 대화상자와 `inert`를 쓴다. |
| JSON · 매니페스트 · ID | 구조를 갖춘 데이터, 읽어 올 파일 목록, 문장 하나의 고유 번호다. | 거장의 문장은 매니페스트로 여러 파일을 읽는다. 문장 ID는 저장과 문장별 풀이를 연결한다. |
| Fetch · 지연 로딩 | 브라우저에서 파일을 불러온다. 지연 로딩은 필요해질 때 처음 읽는 방식이다. | 두 모음은 첫 선택 때 데이터를 읽고, 같은 페이지에서는 읽은 결과를 다시 쓴다. |
| Fisher–Yates 셔플 | 배열을 뒤에서부터 훑으며 무작위 위치와 바꿔 전체 순서를 섞는다. | 목록과 한 장씩에서 공유하는 `readingOrder`를 만든다. |
| 검색 필터 · 더 보기 | 검색 필터는 조건에 맞는 항목을 골라낸다. 더 보기는 그중 화면에 그리는 수를 늘린다. | 검색어와 주제를 함께 적용한다. 목록은 한 번에 40개씩 보여 준다. |
| `details` · `summary` | 웹 브라우저가 기본 제공하는 접기·펼치기와 제목이다. | 한글 읽기, 맥락·적용 질문, 출처에 쓴다. |
| `localStorage` | 같은 브라우저와 사이트 주소에 남는 작은 저장 공간이다. | 즐겨찾기만 기기에 저장한다. 랜덤 이야기 진행은 페이지가 열린 동안 기억한다. |
| Web Speech API · TTS | 브라우저가 글자를 읽어 주는 기능이다. | `speechSynthesis`로 영어 듣기를 실행한다. 음성 종류는 기기에 따라 다르다. |
| ARIA · 키보드 초점 | ARIA는 화면 읽기 도구에 선택·펼침·알림을 전한다. 초점은 키 입력을 받는 위치다. | `aria-pressed`, `aria-expanded`, `role="status"`로 상태를 알리고 읽기 창이 닫힐 때 초점을 돌려준다. |
| GitHub · 커밋 · Vercel | GitHub는 파일과 변경 이력을 두는 곳, 커밋은 한 번의 변경 기록, Vercel은 앱을 웹에 올리는 곳이다. | 운영 앱은 `main`에서 정적 배포한다. 문서와 코드 버전을 커밋으로 대조할 수 있다. |
| Lucian UI 요소 | 검색창이나 책갈피 같은 조작부에 적용한 디자인 참고 부품이다. | #048 선택 밑줄, #092 검색 복구, #012 책갈피를 기존 앱 동작에 연결했다. |
